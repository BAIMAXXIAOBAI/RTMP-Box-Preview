# RTMP Box Preview

📱 软件简介  
RTMP Box Preview 是一款轻量级、高性能的 Android RTMP 服务器工具。它允许您将手机变身为流媒体服务器，接收来自 Xiaomi AI Glass、OBS、FFmpeg 或运动相机的视频推流，并支持实时预览与本地录制。

---

## 🚀 快速开始

### 启动服务
- 确保手机已连接 Wi-Fi（推荐）或开启热点。
- 点击底部的 “启动服务器” 按钮。

### 获取推流地址
- 顶部状态栏会显示当前的推流地址，格式通常为：`rtmp://192.168.x.x:1935/live/stream`。
- 点击地址右侧的 复制图标 即可复制到剪贴板。

### 开始推流
- 在推流端（如 Xiaomi AI Glass, OBS 等）填入上述地址，开始推流。

### 预览画面
- 推流成功后，开启 “预览” 开关，即可在手机屏幕上实时查看视频画面。

## 🎥 视频录制指南
本软件支持将接收到的视频流保存到本地相册。请在录制前根据需求选择合适的封装格式：

### 选项 A：FLV 格式（🛡️ 安全推荐）
- 适用场景：取证录像、长途记录、环境不稳定的长时间录制。
- 特点：采用流式写入技术。极度安全，即使录制过程中遭遇 App 闪退、手机断电或被系统强制杀后台，已录制的内容依然完好无损。
- 注意：部分系统相册可能无法直接预览，建议使用 VLC 或 MX Player 播放。

### 选项 B：MP4 格式（📤 分享推荐）
- 适用场景：短视频录制、需要快速分享给朋友。
- 特点：兼容性极佳，录制后可直接在系统相册查看，支持一键分享到微信、QQ 等平台。
- ⚠️ **风险警告**：抗风险能力差。MP4 必须正常点击“停止”才能生成文件索引。如果录制意外中断（如崩溃、断电），整个视频文件将损坏且无法修复。

## ❓ 常见问题 (Q&A)
### Q: 为什么推流连接失败？
A: 请检查推流设备（如 OBS、智能眼镜）是否与手机连接在同一个 Wi-Fi 网络或热点下，并确认 IP 地址输入无误。

### Q: 录制的视频保存在哪里？
A: 视频默认保存在手机内部存储的 `DCIM/RtmpVideo` 目录下。

### Q: 为什么录制的 FLV 视频无法播放？
A: FLV 是流媒体专用格式，大多数手机自带的系统播放器不支持该格式。请下载安装 VLC for Android、MX Player 或 IINA 等第三方全能播放器进行观看。

### Q: 为什么在系统相册里找不到录制的 FLV 视频？
A: 由于系统相册无法识别 FLV 格式，通常会自动将其隐藏（虽然文件真实存在）。
- 方法 1：使用 “文件管理” App，进入 `DCIM/RtmpVideo` 文件夹即可找到。
- 方法 2：打开 VLC 等第三方播放器，它们通常能扫描并显示出这些视频。

### Q: 为什么录制的 MP4 视频提示“文件损坏”或无法播放？
A: 这通常是因为录制过程意外中断（如：手机没电关机、App 崩溃或被强行划掉后台）导致的。
- 原因：MP4 格式必须在点击“停止”按钮后写入文件索引才能生效。如果没有正常结束，文件虽然占用了空间，但实质上已经彻底损坏且极难修复。
- 建议：对于不可重来的重要录制，请务必使用 FLV 格式，它不怕断电。
